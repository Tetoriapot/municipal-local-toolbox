データ管理

すべての記録、基本情報、メモをJSONファイルに保存・復元します。

バックアップ

読込みは現在のデータ全体を置き換えます。必要な内容を先に書き出してください。10MB以下の、このツールのJSONファイルを読み込めます。配布確認版のJSONにも対応しています。

ファイルの移動・改名、ブラウザの変更、閲覧データの削除に備え、定期的にJSONを書き出してください。

印刷

「すべての記録を印刷」は全分類、基本情報、メモを印刷します。検索・絞り込みの影響を受けません。「表示中の一覧を印刷」は現在の分類や検索結果だけを印刷します。

すべてのデータを削除

削除するのはこのバージョンの確定済みデータです。下書きは「下書きを削除」で別に削除してください。旧版の保存領域と、書き出したJSONファイルは削除しません。

使い方

  1. 担当業務などの分類を選び「新規登録」を押します。
  2. 必要な情報を入力し「登録する」を押します。保存された記録は「編集」で変更できます。
  3. 引継ぎ内容を確認したら「確認済み」にチェックします。ホームで確認の進捗を見られます。
  4. 作業後は「バックアップを書き出す」でJSONを保存してください。

年間予定

4月から翌年3月の順で月別に表示します。「実施時期・締切」に日付や上旬・月末などを記録してください。日付の自動計算や通知はありません。

保存と編集

基本情報とメモは入力時に自動保存します。各分類の編集はダイアログの「登録する」「変更を保存」で確定します。未確定の内容はバックアップに含まれません。

ブラウザ内の保存に失敗した場合は、画面上に「未保存」と表示します。画面を閉じる前にJSONを書き出してください。同じツールを複数のタブで編集すると、他のタブの変更を検出して保存を止めます。現在の内容を書き出してから、保存済みデータを読み直してください。

旧版からの移行

同じ保存場所で旧版のメモを見つけた場合は、新しい保存領域に複製します。旧版の領域は変更しません。自動で見つからない場合は、旧版でJSONを書き出して読み込んでください。

ファイルの場所・連絡先

パス、URL、メールアドレスは文字として記録します。リンクを自動で開いたり、外部へ接続したりしません。ファイルそのものは添付・保存しません。

下書きとサンプル

編集の下書きはツールごとに1件保存します。「下書きを残して閉じる」で中断し、「下書きを再開」で続けられます。登録・保存するまで通常のJSON・印刷には含みません。下書きの書出しは内容の保管用で、通常のバックアップ読込みには使えません。

「サンプルで試す」は架空データを別画面で開きます。通常のデータや下書きは読み書きしません。変更は再読込みで消え、初期サンプルに戻ります。

情報の取り扱い

個人情報・機密情報を入力する場合は所属組織の情報セキュリティポリシーを確認してください。保存内容とJSONは暗号化されません。

Microsoft Edge / Google Chromeを主要な対応対象としています。Internet Explorerには対応しません。記録は合計3,000件、JSONは10MBまでです。ブラウザの保存可能容量は設定や環境により異なります。

新規登録

「必須」とある項目を入力してください。登録・保存するまで一覧には反映されません。

全データの削除を確認

すべての記録、基本情報、メモを削除します。取り消せません。必要な内容を先にJSONへ書き出してください。下書きは残るため、専用の削除操作で別に削除してください。
